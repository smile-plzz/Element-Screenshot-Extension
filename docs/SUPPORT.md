# Support and Feedback for ElementShot

Thank you for using ElementShot!

---

## Getting Help

### 1. Issues and Bug Reports
If you encounter a bug or unexpected behavior:
1. Check the [Known Issues and Limitations](https://github.com/smile-plzz/Element-Screenshot-Extension#readme) section in the README.
2. Search existing issues at [GitHub Issues](https://github.com/smile-plzz/Element-Screenshot-Extension/issues).
3. If your issue is new, please open an issue with:
   - Your browser version (Chrome, Edge, or Firefox).
   - Your operating system.
   - The webpage URL where the issue occurred (if public).
   - Steps to reproduce the issue.

### 2. Feature Requests
Have an idea to make ElementShot even better? Feature requests are welcome on [GitHub Discussions](https://github.com/smile-plzz/Element-Screenshot-Extension/discussions) or [GitHub Issues](https://github.com/smile-plzz/Element-Screenshot-Extension/issues).

### 3. Keyboard Shortcut Customization
If the default shortcut (`Alt+Shift+S`) conflicts with an existing operating system or browser shortcut:
- In Google Chrome or Brave: Open `chrome://extensions/shortcuts`
- In Microsoft Edge: Open `edge://extensions/shortcuts`
- In Firefox: Open `about:addons`, click the gear icon, and select "Manage Extension Shortcuts".
