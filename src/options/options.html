ElementShot Settings

Component-aware element screenshot configuration

Output Actions

Copy to Clipboard Automatically write the captured PNG to your system clipboard ready to paste.
Save to Disk Automatically save the PNG image into your Downloads folder.

File Storage and Naming

Images will be saved into Downloads/<subfolder>/.
Available tokens: {domain}, {tag}, {class}, {id}, {title}, {date}, {time}.
