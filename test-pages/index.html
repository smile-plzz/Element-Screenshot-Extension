ElementShot Test Pages

Use these test fixtures to verify ElementShot in Google Chrome and Microsoft Edge.

Verification Checklist

  • Press Alt+Shift+S or click toolbar icon to enter pick mode.
  • Hover over elements to see highlight box and tag label.
  • Press F to freeze hover state while inspecting.
  • Press ↑ and ↓ to traverse parent/child hierarchy.
  • Click to capture: verify toast confirmation, clipboard paste in chat/editor, and file saved in Downloads/ElementShots/.
  • Press Esc to cancel without capturing.

Test Scenarios

  • 1. Standard UI Components: Cards, badges, buttons, forms, and responsive grids.
  • 2. Long Page & Sticky Headers: Sticky navigation, tall scroll elements, viewport boundary clipping.
  • 3. CSS Transforms: Rotated elements, skewed banners, scaled cards, and CSS flex/grid.
  • 4. Shadow DOM Elements: Web components with open shadow roots (deep element inspection).
